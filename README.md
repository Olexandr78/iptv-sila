# IPTV-СИЛА для Windows

Полноценная настольная программа Windows: IPTV-клиент и встроенный LAN-сервер в одном приложении. Интерфейс — PySide6/Qt Widgets, не HTML и не браузер.

## Возможности
- Загрузка M3U/M3U8 из файла или URL.
- Поиск каналов по названию и категории.
- Воспроизведение потоков через Qt Multimedia.
- «Кошачий ТВ» с плавной анимацией.
- Встроенный HTTP-сервер для раздачи локального M3U в LAN.
- Кнопка запуска/остановки сервера и отображение LAN-адреса.
- Сохранение настроек.

## Запуск из исходников
```powershell
py -m pip install -r requirements-build.txt
py app.py
```

## Сборка EXE
GitHub Actions → ветка windows → последний запуск → Artifacts. Архив содержит IPTV-SILA.exe и Qt-библиотеки; Python на компьютере пользователя не требуется.

## Использование
1. Открой IPTV-SILA.exe.
2. На вкладке IPTV-клиента выбери M3U-файл или URL и нажми «Загрузить».
3. Дважды щёлкни канал для воспроизведения.
4. На вкладке Сервер выбери локальный M3U, порт 8765 и нажми «Запустить сервер».
5. На другом устройстве в той же Wi-Fi сети используй адрес http://IP-компьютера:8765/api/playlist.

Воспроизведение зависит от кодеков и форматов, поддерживаемых Qt Multimedia в Windows. Может потребоваться разрешить приложение в Брандмауэре Windows. Программа не содержит встроенных каналов — используй только легально доступные плейлисты.
