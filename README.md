# IPTV-СИЛА

Лёгкий IPTV-сервер для Windows со встроенным веб-клиентом. Один сервер на ПК раздаёт интерфейс и плейлист другим устройствам в домашней Wi-Fi/LAN сети.

## Возможности

- Windows: сервер запускается через `start.bat`, клиент открывается в браузере.
- Телефоны и другие компьютеры: тот же адаптивный клиент открывается по LAN-адресу сервера.
- Плейлисты M3U/M3U8, поиск каналов и воспроизведение HLS (через hls.js).
- Встроенный «Кошачий ТВ»: спокойная анимация с синими и жёлтыми оттенками, без мигания.
- Никаких аккаунтов и телеметрии.

## Запуск на Windows

1. Установи Python 3 (при установке отметь **Add Python to PATH**).
2. Скачай репозиторий.
3. Запусти `start.bat`.
4. На самом ПК открой `http://127.0.0.1:8765`.
5. На телефоне или другом ПК в той же сети открой LAN-адрес, который напечатает сервер, например `http://192.168.1.20:8765`. Разреши Python доступ в частной сети в брандмауэре Windows.

## Подключение плейлиста

- Положи свой легально доступный `playlist.m3u` в корень проекта; или
- скопируй `config.example.json` в `config.json` и впиши URL в поле `playlist_url`.

Сервер отдаёт плейлист через `/api/playlist`. Не публикуй приватные URL плейлистов и данные подписки в открытом репозитории.

## Важно

Это базовая версия. На iPhone/iPad и Android приложение пока работает как веб-клиент в браузере, а не как отдельный APK/IPA. Поддержка конкретных потоков зависит от формата, браузера, сети и прав доступа к трансляции. Сам проект не поставляет платные или пиратские каналы.

«Кошачий ТВ» — декоративная анимация. Кошки лучше различают сине-жёлтую часть спектра, но восприятие зависит от яркости, контраста и движения; не оставляй питомца без присмотра у экрана.
