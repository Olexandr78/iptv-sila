# IPTV-СИЛА — native iOS

Эта ветка содержит **отдельное нативное приложение для iPhone/iPad**, написанное на Swift + UIKit. В приложении нет Python runtime, Cordova, Capacitor, WebView или симуляторной сборки.

## Реализация

- UIKit-интерфейс с минимальной версией iOS 12.0 (в том числе iPhone 6).
- AVFoundation / AVPlayer для воспроизведения HLS и других медиапотоков, поддерживаемых iOS.
- URLSession загружает M3U с локального IPTV-СИЛА сервера по адресу `http://IP-компьютера:8765`.
- Поиск каналов и вкладка «Кошачий ТВ».
- Windows-сервер остаётся отдельной программой; iPhone подключается к нему по Wi-Fi/LAN.

## Сборка для настоящего устройства

GitHub Actions запускает Xcode с SDK `iphoneos`, `generic/platform=iOS` и архитектурой `arm64`. Это сборка для физического iPhone, не iOS Simulator. IPA появляется во вкладке Actions → последний запуск → Artifacts.

### Подпись и установка

CI собирает **unsigned IPA**. Такой файл не устанавливается обычным способом на iPhone: для стандартной установки нужна подпись Apple и provisioning profile. Для личной установки можно использовать совместимый sideloading; на jailbreak-устройстве — подходящий механизм установки неподписанных приложений. Компиляция ещё не означает, что файл уже подписан или проверен на самом iPhone.

Используется UIKit, а не SwiftUI, чтобы сохранить совместимость с iOS 12 / iPhone 6. Потоки воспроизводятся через AVPlayer; поддержка конкретного кодека зависит от iOS и устройства.

Используй только плейлисты и трансляции, к которым у тебя есть законный доступ.
