# IPTV-СИЛА — iOS

Полноценный нативный проект Xcode на Swift + UIKit + AVPlayer. Никаких Python runtime, WebView, Capacitor или эмуляторов.

Возможности исходной версии: IPTV-плейлист с сервера IPTV-СИЛА, список и поиск каналов, воспроизведение AVPlayer, украинские M3U-источники с проверкой доступности, кошачий экран.

## Сборка
Откройте `IPTV-SILA.xcodeproj` в Xcode и соберите схему `IPTV-SILA`. GitHub Actions собирает приложение для iOS Simulator без подписи. Установка на физический iPhone и выпуск IPA требуют подписи Apple Developer и provisioning profile.
