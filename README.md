# IPTV-СИЛА

IPTV-СИЛА — единый клиент для Windows, Android и iOS плюс локальный Windows-сервер.

## Автоматические сборки

GitHub Actions собирает артефакты при каждом push в `main` и по тегам `v*`:

- **Windows x64** — переносимая папка с `IPTV-SILA.exe`, сервером и веб-клиентом. Python на компьютере пользователя не требуется.
- **Android** — debug APK (для тестирования и ручной установки).
- **iOS Simulator** — unsigned-приложение для запуска в симуляторе Xcode.

Результаты находятся во вкладке **Actions → последний запуск → Artifacts**.

### Важное ограничение iOS

Сборка для симулятора не устанавливается на настоящий iPhone/iPad. Для подписанного IPA и установки на реальные устройства нужен Apple Developer signing: сертификат и provisioning profile. Эти секреты нельзя хранить в открытом репозитории; их следует добавить в GitHub Actions Secrets. Пока подпись не настроена, workflow честно выдаёт только сборку симулятора.

## Windows

1. Скачай артефакт `IPTV-SILA-Windows-x64` из Actions.
2. Распакуй папку.
3. Запусти `IPTV-SILA.exe`.
4. Открой `http://127.0.0.1:8765`.
5. Другие устройства в той же сети могут подключиться по LAN-адресу компьютера.

В комплекте есть `config.example.json`. Скопируй его в `config.json` и укажи `playlist_url`, либо положи свой легально доступный `playlist.m3u` рядом с EXE.

## Android и iOS

Мобильные сборки используют общий интерфейс. В приложении укажи адрес запущенного Windows-сервера, например `http://192.168.1.20:8765`. Телефон и ПК должны быть доступны друг другу по сети. Для удалённого доступа через интернет нужен отдельно настроенный защищённый сервер/VPN; не выставляй открытый порт в интернет без защиты.

## Возможности

- M3U/M3U8, поиск каналов и HLS-плеер.
- «Кошачий ТВ» со спокойной сине-жёлтой анимацией.
- Windows-сервер отдаёт веб-клиент и плейлист другим устройствам.
- Нет аккаунтов и телеметрии.

Проект не поставляет каналы. Используй только плейлисты и трансляции, к которым у тебя есть законный доступ.

## Отдельные платформенные ветки

Для независимой разработки и сборки созданы три ветки:

- `windows` — отдельный Windows x64 portable build.
- `android` — отдельная сборка Android debug APK.
- `ios` — legacy-сборка iOS с минимальной целью iOS 12.0; workflow собирает неподписанный IPA для тестирования на совместимом джейлбрейкнутом устройстве.

У каждой ветки свой файл `.github/workflows/build.yml`. Push в соответствующую ветку запускает только её платформенную сборку. Общая ветка `main` сохраняет единый workflow для сборки всех платформ.

**Важно:** iOS IPA не подписан. Он предназначен для установки через совместимый jailbreak-инструментарий (например, AppSync/Filza, если поддерживается установленной прошивкой). Для обычной установки на iPhone без джейлбрейка потребуется подпись Apple и provisioning profile. Совместимость конкретного iPhone 6 и iOS 12.5.8 нужно подтвердить реальной установкой и запуском.
