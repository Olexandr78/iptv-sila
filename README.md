# IPTV-СИЛА — Android

Полностью нативное Android-приложение: **Kotlin + Android SDK + AndroidX Media3 (ExoPlayer)**.

В проекте нет Python runtime, WebView, Capacitor или JavaScript-обёртки.

## Функции
- Открытие локальных M3U/M3U8 через системный выбор файла.
- Загрузка трёх публичных украинских IPTV-подборок.
- Проверка доступности самих плейлистов и подсчёт записей EXTINF.
- Поиск каналов и воспроизведение через Media3.
- Поддержка относительных URL в M3U.

Проверка M3U не гарантирует, что каждый отдельный видеопоток доступен.

## Сборка
Проект собирается Gradle-задачей `assembleDebug`. GitHub Actions публикует APK в артефактах запуска workflow.
